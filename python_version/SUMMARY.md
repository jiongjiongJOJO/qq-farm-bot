# Python版本实现总结

## 项目概述

本项目成功实现了QQ农场挂机脚本的Python版本，完全采用面向对象设计和模块化架构，代码清晰易维护。

## 实现的核心类

### 1. 配置管理 (`Config`)
- 集中管理所有配置项
- 支持运行时修改
- 定义游戏相关枚举

### 2. 网络通信 (`NetworkClient`)
- WebSocket连接管理
- 消息编解码
- 用户登录和状态管理
- 心跳保活机制

### 3. 农场操作 (`FarmOperations`)
- 完整的农场操作封装
- 自动巡查循环
- 智能作物管理

### 4. 好友操作 (`FriendOperations`)
- 好友农场访问
- 帮助和偷菜功能
- 自动巡查机制

### 5. 任务系统 (`TaskSystem`)
- 自动领取任务奖励
- 支持分享翻倍

### 6. 仓库系统 (`WarehouseSystem`)
- 自动出售果实
- 定时售卖循环

### 7. 状态显示 (`StatusBar`)
- 实时状态更新
- 终端UI显示

### 8. 游戏配置 (`GameConfig`)
- 植物数据管理
- 等级经验表

### 9. 经验计算 (`ExpCalculator`)
- 经验效率分析
- 最优作物推荐

### 10. 邀请处理 (`InviteProcessor`)
- 邀请码自动处理
- 微信好友申请

## 使用说明

### 安装依赖
```bash
cd python_version
pip install -r requirements.txt
```

### 运行程序
```bash
# QQ小程序
python client.py --code YOUR_CODE

# 微信小程序
python client.py --code YOUR_CODE --wx

# 自定义间隔
python client.py --code YOUR_CODE --interval 5 --friend-interval 2
```

### 查看帮助
```bash
python client.py --help
```

### 运行测试
```bash
python tests/test_basic.py
```
